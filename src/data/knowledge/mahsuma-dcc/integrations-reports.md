# التكاملات والتقارير

## التكاملات المتاحة

- استيراد Excel و CSV لقيم المؤشرات (جميع الباقات).
- موصل Power BI للقراءة (باقة المنشأة فأعلى).
- واجهة REST API مع مفاتيح وصول لكل منشأة (باقة المنشأة فأعلى).
- SSO عبر Azure AD أو أي مزود SAML (باقة الجهات).

## التقارير الدورية

تُولَّد تقارير PDF شهرية وربع سنوية تلقائياً وتُرسل للمدير التنفيذي ومن يحدده. يمكن تخصيص الشعار والهوية في باقة المنشأة فأعلى.

## الدعم

- باقة الفريق: بريد إلكتروني خلال 48 ساعة عمل.
- باقة المنشأة: دعم أولوية خلال 8 ساعات عمل.
- باقة الجهات: مدير نجاح مخصص ودعم هاتفي.
