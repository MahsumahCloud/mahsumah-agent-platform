## ملاحظات وتوصيات قبل الإنتاج

1. **الأدوات الوهمية غير مقيّدة بالشركة**: `fetch_billing_summary` و`check_project_status` تعيد بيانات ثابتة لأي tenant. عند الربط الحقيقي يجب أن يكون `ctx.principal.tenantId` هو المفتاح الوحيد للاستعلام (موضح في README).
2. **الثقة للردود الحوارية/الرفض** تُسقَّف عند 45% وتُعلَّم "تحويل" (H3, H10). هذا مقصود ليصل الطلب لبشر، لكن راقب شاشة "أسئلة منخفضة الثقة" حتى لا تمتلئ بالتحيات؛ الردود الحوارية البحتة معفاة.
3. **Rate limit في الذاكرة**: مناسب لنسخة واحدة؛ مع أكثر من replica انقل المفتاح إلى Redis (نفس الواجهة).
4. **النطاقات المسموحة للزوار** فارغة الآن (= أي نطاق). أضف نطاقات المواقع الفعلية قبل النشر.
5. **مفتاح Anthropic** مرتبط بحساب شخصي وينتهي خلال 30 يوماً؛ للإنتاج أنشئ مفتاحاً بحساب خدمة وبلا انتهاء.
6. **تكلفة**: متوسط الطلب ~600 token خرج؛ prompt caching مفعّل على طبقة النظام. راقب `usage` في المحادثات.
