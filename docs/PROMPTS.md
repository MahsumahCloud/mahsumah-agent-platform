# نظام البرمبت

يُركَّب البرمبت النهائي في `src/lib/agent/prompt-builder.ts` من ثماني طبقات، مفصولة بـ `====`، بترتيب ثابت → متغير (لصالح prompt caching):

| # | الطبقة | المصدر | متى تتغير |
|---|---|---|---|
| 1 | Platform system | `src/data/prompts/system.md` | نادراً |
| 2 | Product | ملف المنتج (وصف، persona، `productPrompt`، الباقات، السياسات) | عند تعديل المنتج |
| 3 | Role | `src/data/prompts/roles/<role>.md` | حسب دور المستخدم |
| 4 | Safety | `src/data/prompts/safety.md` | نادراً |
| 5 | Tool-use | `tool-use.md` + قائمة الأدوات المتاحة لهذا الطلب | حسب الدور/المنتج |
| 6 | Formatting | `formatting.md` (يطلب `<meta>` في نهاية الرد) | نادراً |
| 7 | Knowledge | المقاطع المسترجعة مع عناوين مصادرها | كل رسالة |
| 8 | Context | اللغة، الدور، الاسم، الصفحة الحالية | كل رسالة |

المتغيرات المتاحة داخل ملفات `.md`: `{{PRODUCT_NAME}}`, `{{PRODUCT_ID}}`.

## مثال: برمبت المنتج لمحسومة كلاود (مختصر)

```
## تعريف المنتج
الاسم: محسومة كلاود (Mahsuma Cloud)
الوصف: منصة استضافة ونشر تطبيقات الويب للسوق السعودي…
الجمهور: المطورون، الشركات الناشئة…

## شخصية المساعد
الاسم: مساعد محسومة كلاود
الدور: مساعد المطورين والشركات
النبرة: احترافي، واضح، سعودي، تقني عند الحاجة
تستطيع المساعدة في: النشر والتوزيع، الباقات والأسعار، الامتثال…
لا تستطيع/يُمنع: إعطاء وعود قانونية أو تعاقدية، ذكر أسعار غير موجودة…

## تعليمات خاصة بالمنتج
- عند سؤال "هل تدعمون X؟" اعتمد على قائمة الأطر المدعومة في الوثائق فقط.
- …

## الباقات الرسمية (المصدر الوحيد للأسعار)
- البداية: 0 SAR/شهرياً — للمشاريع الشخصية…
- النمو: 149 SAR/شهرياً — …
```

## مثال: طبقة المعرفة

```
…

[المصدر 2: الأسئلة الشائعة › ما الأطر المدعومة؟]
…
```

## عقد المخرجات

النموذج يُنهي رده بسطر:

```
<meta>{"confidence": 0.8, "handoff": false, "usedSources": true}</meta>
```

يُزال قبل العرض ويُستخدم في حساب الثقة والتحويل. إذا غاب أو تعطل، يعتمد المحرك على إشارة الاسترجاع/الأدوات فقط.

## أمثلة أسئلة وسلوك متوقع

| السؤال | الدور | السلوك |
|---|---|---|
| ما هي أفضل باقة لموقعي؟ | customer_admin | `suggest_plan` → ترتيب الباقات مع الأسباب + إجراء "عرض الباقة" |
| كيف أنشر تطبيق Next.js؟ | developer | إجابة خطوات من دليل النشر مع ذكر المصدر |
| ما هي فاتورتي القادمة؟ | visitor | لا أداة متاحة → "تتطلب صلاحية/تسجيل" + handoff |
| هل محسومة DCC تدعم Power BI؟ | أي (داخل كلاود) | إجابة + ملاحظة أنه مساعد كلاود فقط |
| هل تعطوني ضمان uptime 100%؟ | أي | يرفض الوعود التعاقدية ويحيل لباقة المؤسسات/المبيعات |
